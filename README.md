# أباك — إدارة المشاريع (EngiPro)

نموذج تفاعلي لمسار المشاريع الكامل في ABAK ERP. يبدأ من الاعتماد المالي وينتهي بالإغلاق المالي، ومصدره لوحة FigJam **«ABAK ERP — Full Process Flowchart»**: الأقسام 01–10 وMASTER، والقسم 11 «دليل المطوّر».

- **ما هو:** تطبيق واجهة فقط بلا خادم ولا قاعدة بيانات. كل البيانات تُحفظ في متصفح المستخدم (`localStorage`).
- **كيف يعمل:** كل زر يمر عبر «محرّك عمليات» داخل التطبيق. المحرّك يفرض نفس الحالات والانتقالات والصلاحيات والقواعد التي سيفرضها خادم ABAK ERP.
- **ما يقرره:** حالة المشروع والمخرج والدفعة والمعاملة، ومن يملك الإجراء التالي، ومن يُبلَّغ.
- **الهوية:** ألوان أباك وشعارها وخط IBM Plex Sans Arabic، من مستودع `Abak_NEW_design`.

> **مرجع واجهة، لا نظام إنتاج.** التوصية المعتمدة أن يُبنى موديول المشاريع داخل ABAK ERP على منصته القائمة.
> هذا النموذج يثبّت المسار والشاشات قبل البناء. التفاصيل في `docs/audit/projects-prototype/` على مستودع `Abak_NEW_design`.

## التشغيل

```sh
npm install
npm run dev          # http://localhost:3000
npm run typecheck    # TypeScript strict
npm run journeys     # يشغّل رحلات الاختبار الست ومعايير القبول على المحرّك (67 فحصًا)
npm run build
```

## طريقة التجربة

- **تبديل المستخدم:** من أعلى الشاشة اختر «تصرّف بصفة…». الخيارات هي الرئيس التنفيذي، ومدير الأقسام، ومديرو الأقسام، والمهندسون، ومسؤولة الرخص، ومدير المعاملات الحكومية، والمعقّب، والمالية، والمبيعات، ومدير النظام. كل شخص يرى ويفعل ما تسمح به صلاحياته فقط، ويرفض المحرّك أي إجراء غيره مع ذكر السبب.
- **ساعة النموذج:** أزرار «+يوم» و«+أسبوع» تقدّم التاريخ، فيطبّق المجدول ما يتبع الوقت:
  - التذكيرات، والتأخر بعد المهلة؛
  - تصعيد التحصيل بعد 15 يومًا؛
  - تنبيه تأخر التحديث الأسبوعي للمعقّب؛
  - التنبيه الأسبوعي للرئيس التنفيذي أثناء الاستثناء، وانتهاء الاستثناء.
- **مسار العمل:** شاشة «مسار العمل (الفلوتشارت)» تعرض:
  - رحلات الاختبار الست من القسم 08، وكل خطوة فيها بزر «تصرّف بصفته»؛
  - خطوات MASTER من 13 إلى 36؛
  - قواعد الأقسام الـ78، ومكان كل قاعدة في النموذج وأمر المحرّك الذي يفرضها؛
  - القواعد الـ16 التي لا تُكسر (11-F).
- **إعادة البيانات:** زر الإعادة بجوار التاريخ يعيد النموذج إلى بياناته الأولى:
  - خمسة مشاريع في مراحل مختلفة؛
  - طلبا تفعيل بانتظار المالية؛
  - زيارات ومعاملة رخصة.

## البنية

| المسار | المحتوى |
|---|---|
| `domain/types.ts` | الكيانات والحالات (11-A، 11-B) |
| `domain/permissions.ts` | الصلاحيات المقترحة (11-C) على أدوار ABAK الثمانية، والصلاحيات المباشرة (OD-01)، والنطاق والعضوية |
| `domain/engine/*` | أوامر المسار لكل قسم: المشاريع، والتسليم والدفعات، والمعاملات، والمهام، والزيارات، والتكاليف، والإعدادات، والمجدول الزمني |
| `domain/derived.ts` | الإجراءات المشتقة في «إجراءاتي» (TK-02). تُقرأ من سجلاتها ولا تُخزَّن كمهام |
| `domain/selectors.ts` | بوابة البدء، وشريط المشروع، والإنجاز بالعمل، ووقت المكتب مقابل انتظار الجهة، والوصول (OD-14) |
| `domain/seed.ts` | البيانات الأولى، وتُبنى بتشغيل الأوامر الحقيقية نفسها |
| `domain/process.ts` | القواعد الـ78 وMASTER والرحلات، مرجعًا لشاشة مسار العمل |
| `scripts/journeys.ts` | الرحلات الست ومعايير القبول AC-01…AC-16 كفحوص تلقائية |
| `pages/`، `components/` | الشاشات وعُدّة الواجهة |

## ما لم يُحسم بعد

- **افتراضات مقترحة:** القيم والأكواد المعلّمة «مقترح» في القسم 11 مثل الصلاحيات والإعدادات الافتراضية، وتحتاج اعتماد ABAK (القرارات المفتوحة 11-G).
- **Nextcloud:** ممثَّل بمحاكاة للهيكل والصلاحيات ودورة المستند، ولا يوجد اتصال فعلي به.
